# Google APIs for Node.js (Location & Maps Related)

### 1. Google Maps Geocoding API

* **Purpose:** Convert an address to latitude/longitude coordinates or vice versa.
* **Example:**
  `"1600 Amphitheatre Parkway, Mountain View"` → Coordinates (lat, lng).

### 2. Google Places API

* **Purpose:** Search for nearby places such as restaurants, shops, hospitals, etc.
* **Features:**

  * Nearby search
  * Text search
  * Place autocomplete
  * Place details

### 3. Google Place Details API

* **Purpose:** Retrieve detailed information about a specific place.
* **Details include:** Opening hours, phone number, user reviews, and more.

### 4. Google Maps Directions API

* **Purpose:** Get routes and directions between two locations.

### 5. Google Maps Distance Matrix API

* **Purpose:** Calculate distance and estimated travel time between multiple locations.

### 6. Google Maps Roads API

* **Purpose:** Snap GPS points to roads (useful for vehicle tracking and map matching).

### 7. Google Maps Time Zone API

* **Purpose:** Obtain timezone information for any given geographic coordinate.

### 8. Google Maps Elevation API

* **Purpose:** Get elevation data (height above sea level) for a location.

### 9. Google Maps Static Maps API

* **Purpose:** Generate static image maps for use in applications or emails.

### 10. Google Maps JavaScript API

* **Purpose:** Display interactive maps in web browsers or frontend applications.
